# 清流：B站视频过滤器

一个本地优先的 Edge/Chrome 扩展。它从 B站获取推荐候选，按关键词、UP主粉丝数和视频播放量进行过滤，在独立页面中只渲染全部条件通过的视频。

本项目只负责视频过滤，不包含视频下载、字幕转写、AI 总结、本地模型或本机服务。

## 功能

- 屏蔽标题、简介和实际标签中命中关键词的视频；
- 可选择是否检查 UP主名称；
- 设置 UP主粉丝数的最低和最高门槛；
- 设置视频播放量的最低和最高门槛；
- 三项全部通过后才创建视频卡片；
- 粉丝数或视频详情无法确认时默认不显示；
- 自动补取候选，每轮最多检查 120 个；
- 个性化推荐不可用时自动使用热门视频候选；
- 粉丝数缓存 24 小时，视频详情缓存 6 小时。

## 安装

1. 下载或克隆本仓库；
2. 在 Edge 打开 `edge://extensions`，Chrome 打开 `chrome://extensions`；
3. 开启“开发人员模式”；
4. 点击“加载解压缩的扩展”；
5. 选择仓库中的 `extension` 文件夹；
6. 将“清流：B站视频过滤器”固定到工具栏。

安装后点击一次扩展图标，即可打开过滤首页。不需要提前打开 B站首页，也不需要运行本地服务器。

## 默认规则

- 屏蔽词：`破防`、`急了`、`对线`、`开战`、`逆天`；
- UP主粉丝数：`1万～500万`；
- 视频播放量：`5000～100万`；
- 检查标题、简介和标签，不检查 UP主名称。

所有规则都可以在过滤页面左侧修改。数值边界为包含关系，例如最低粉丝数为 10000 时，粉丝数恰好为 10000 的视频可以通过。

## 工作原理

```text
B站推荐候选
  → 标准化数据
  → 关键词与播放量预筛
  → 查询剩余视频的详情与UP主粉丝数
  → 完整规则判断
  → 仅渲染 accepted 视频
```

候选视频不会先显示再删除。页面只会为最终状态为 `accepted` 的视频创建卡片；查询中、查询失败和条件不通过的视频均不会进入视频列表。

## 测试


## 隐私与限制

- 过滤设置保存在浏览器同步存储中；
- 粉丝数和视频详情缓存在浏览器本地存储中；
- 扩展不会把 Cookie、观看历史或推荐数据发送到第三方服务器；
- 个性化程度取决于当前浏览器中的 B站登录状态；
- 点击视频后会打开 B站原始播放页面；
- B站接口发生变化时，扩展可能需要更新。

本项目与哔哩哔哩官方无关。使用者应遵守网站条款和当地法律法规。
