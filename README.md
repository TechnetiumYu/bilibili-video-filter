# B站视频过滤器

Edge / Chrome 扩展，直接在 B站首页和搜索结果页过滤原生视频卡片。按关键词、准确播放量、UP主粉丝数以及特殊话题个性化门槛判断，全部通过后才显示。

从 v0.8.0 开始，正常打开 B站即可使用；扩展图标打开的是设置与标记库，不再创建独立视频流。无需本地服务器。

## 安装与更新

1. 下载或克隆本仓库；在 Edge 打开 `edge://extensions`，Chrome 打开 `chrome://extensions`。
2. 开启开发人员模式，选择“加载解压缩的扩展”，指定本仓库的 `extension` 文件夹。
3. 更新现有安装时点击扩展的“重新加载”，核对版本为 `0.8.1`，并刷新已打开的 B站页面。
4. 若扩展已禁用，需在扩展管理页重新启用；新版本增加了 B站页面内容脚本，浏览器可能要求确认网站访问权限。

点击扩展图标，或在 B站页面右下角点击“设置 / 标记库”，即可修改规则。旧版设置、标记和模型配置会自动复用，不必卸载重装。

## 使用范围与页面行为

第一版覆盖 `https://www.bilibili.com/` 首页推荐卡片，以及 `https://search.bilibili.com/all`、`/video` 视频搜索卡片。播放器、动态页、UP主空间等页面暂不处理。

- 在 B站原搜索框输入关键词，B站生成结果后，扩展过滤页面中的视频；扩展不再主动调用搜索接口获取候选。
- 未完成检查的视频先显示占位，通过后展示原卡片，不通过则隐藏外层网格项。
- 向下滚动、换一批或切换搜索词时，新增和替换的卡片会自动检查。同一 BV 号复用结果。
- 保存设置后，已打开的 B站页面会遮住视频并按新规则重新检查。
- 右下角显示通过、隐藏、待查和失败数量；“重试失败项”会重新检查失败视频。
- 通过的视频增加发布时间和“标记待分析”按钮，其余原生播放、UP主链接保持可用。
- 首页轮播保留 B站原生网格中的尺寸，隐藏推荐卡片后不会压扁；窗口缩放时重新测量。

插件只处理 B站已经提供的候选，不改变 B站后台推荐算法和排序，也不主动无限翻页。过滤较多时页面视频会减少，可继续使用 B站原生滚动加载、换一批或分页。

## 规则与准确数据

支持标题、简介、标签及可选 UP主名称的关键词屏蔽；粉丝数和播放量都可设置上下限。数值边界包含在允许范围内。

首页展示的“1.2万”等数值经过取整，不适合精确判断。因此扩展从卡片链接提取 BV 号，补查并缓存准确标题、简介、标签、分区、播放量和 UP主 ID，再为仍可能通过的视频查询粉丝数。详情或粉丝数据不完整时不会放行。

默认规则：屏蔽 `破防、急了、对线、开战、逆天`；粉丝数 1万～500万；播放量 5000～100万；检查标题、简介和标签。

## 特殊话题与本地 Qwen

在设置中添加话题，例如“华为”，填写最低播放量、最低粉丝数及置信度。特殊门槛只会收紧全局规则；同时命中多个话题时，各项最低门槛取最大值。

模型关闭时，按话题名称及补充关联词匹配；例如给“华为”补充 `鸿蒙, HarmonyOS`。

启用本地模型后，可只输入“华为”，由模型根据语义识别相关话题。默认接口是 `http://127.0.0.1:8000/v1/chat/completions`，模型名需与用户本地服务一致。

分类请求只向本机发送视频 ID、标题、标签和已有封面 OCR 文字，不发送 Cookie、粉丝数、播放量、简介、评论、字幕或弹幕。模型仅输出话题 ID、置信度和证据，门槛由确定性代码执行。模型失败、输出不完整或非法时，相关视频不会放行。

当前未捆绑 OCR 引擎，封面文字字段为空，实际分类输入为标题和标签。分类缓存为 7 天；键包含模型、接口、话题定义、提示版本和视频输入。

## 标记库与讨论样本

在原生卡片点击“标记待分析”，长期保存当时的标题、简介、分区、标签、数值、分类证据、有效门槛、来源和搜索词。在设置页“标记库”查看样本、添加备注、删除或复制 / 导出 JSON。

快照独立于缓存，清除缓存或 7 天分类缓存过期不会删除样本。每个浏览器配置最多保存 1000 个样本。可把导出的 JSON 提供给后续讨论，按具体视频信息调整规则。

## 请求调度与错误

首页补查使用高速模式，单类接口最多 4 并发；搜索补查采用最多 2 并发、约 200～300 毫秒启动间隔。只处理视口附近的视频，每批最多 8 个 BV 号。标题、简介或播放量已不符合时，不再查询粉丝数。

视频详情与粉丝数缓存 24 小时。本地不设置风控冷却，不倒计时，不自动反复重试。遇到 HTTP 412 时停止页面自动检查，未确认的卡片保持遮挡；可立即点击“重试失败项”。B站服务器仍可能限制详情或粉丝接口。

仓库保留了旧版独立流使用的 WBI 签名和备用搜索函数，当前原页面过滤流程不调用它们。

## 开发与验证

需要 Node.js 20.19+（或 22.12+）：

```powershell
npm ci
npm test
```

可选联网测试：运行 `npm run test:live`，使用内存中的默认规则检查一个公开视频的真实详情和粉丝接口，不读取浏览器设置；也可用 `npm run test:live -- BV号` 指定视频。

测试覆盖规则、分类、标记快照、真实后台消息处理、缺失数据 / 412、动态 DOM 新增与复用、迟到响应、设置更新和页面退出。模拟 DOM 测试不能替代 B站实际页面验收；B站卡片结构变动时可能需要调整适配器。

## 隐私与项目边界

设置、缓存和样本保存在浏览器本地，不自动上传。分类仅允许连接本机 localhost / 127.0.0.1。插件不下载或分析视频正文，也不包含字幕转写和 AI 总结项目。
